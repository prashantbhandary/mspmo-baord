# MSPM0 Board

KiCad project for the MSPM0 board.

## Project files

- `mspmo-baord.kicad_pro` - KiCad project settings
- `mspmo-baord.kicad_sch` - Schematic
- `mspmo-baord.kicad_pcb` - PCB layout
- `MSPM0.kicad_sym` - Custom symbols
- `sym-lib-table` - Symbol library configuration

Open `mspmo-baord.kicad_pro` in KiCad to work with the project.
